Changelog for package mocap4r2_tools
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

2.0.0 (2026-11-14)
------------------
* New package, replaces mocap4r2cli: ros2 mocap4r2 list, info, start, stop, bodies, hz, record (rosbag2 capture sessions with metadata), export and doctor (ROS setup, data flow, stamps, route to each server).
* Terminal UI (ros2 mocap4r2 tui): systems, lifecycle, link with the mocap software, rate, latency, drops and bodies, with start/stop (Textual vendored; on Humble it needs a newer Textual from pip).
* Contributors: Francisco Martín Rico
